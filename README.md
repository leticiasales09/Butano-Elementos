# Butano-Elementos
Trabalho Final do componente curricular Banco de Dados.
Projeto com propósitos educacionais onde o usuario pode digitar o nome ou o simbolo de um elemento químico e ser exibido para o usuario o numero atomico, quantas ligações químicas faz e a qual grupos quimico pertence.
programação em HTML e php, com integração a um banco de dados mysql usando os pacotes do XAMPP phoAdmin.
